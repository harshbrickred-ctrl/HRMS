# PeopleOS Mobile

Expo (React Native) ESS client for PeopleOS — Design44 palette aligned with the web app.

## Run

From repo root:

```bash
npm run dev:mobile       # Expo Dev Tools / Expo Go
npm run dev:mobile:web   # http://localhost:8081
```

API base URL defaults to `http://localhost:3000/api/v1`. Override with `EXPO_PUBLIC_API_URL`.

## Web preview (no Expo required)

On http://localhost:5173/login, use the **smartphone** icon to open an in-browser phone demo with the same Design44 look and ESS workflow. Logged-in: **Me → Mobile**.
