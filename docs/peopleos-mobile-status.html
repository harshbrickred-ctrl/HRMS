PeopleOS Mobile

Expo app status by role. Same APIs as the web app. API base https://peopleos-api.vercel.app/api/v1. Date: 19 Oct 2026.

A row is “live” when the screen calls the real API. On the current production database, the employee role had no stored permissions, so attendance, leave, payslips, and helpdesk returned 403. API commit 0fa6b59 grants those permissions from the role itself. Punch buttons turn on only after that build is serving, and only when the tenant policy has web punch enabled.

FeatureWhat you get
Bottom tabsHome, Leave, Attendance, People, More. Web uses a sidebar. The phone uses tabs.
Secure token storageAccess and refresh tokens stay in the device secure store, not in a browser session.
Theme controlLight, dark, or system, from the phone appearance setting.

Role stacksManager, HR, Admin, and Leadership are separate phone screens reached from More, not a second website.
